# LOOKY redesign

Separate local design proposal using the previously supplied pink template. Eighteen product entries use public Instagram photography and captions from https://www.instagram.com/looky__trinkets/. Captured 16 October 2026. Algerian centime shorthand (alf) is converted to DA; original captions are shown in each detail view. Variant-dependent prices use From. One product without a listed price asks visitors to enquire. Availability is not verified live. Orders and payments are not submitted here. No content from Sumyyume is reused.
