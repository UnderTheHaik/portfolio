Privacy, without guesswork.

Thiziri is an Under the Haik project. This information describes this web reader; the Android app has a separate privacy policy.

What stays in this browser

Saved reading IDs, daily counters and language, theme and Arabic text size are stored under thiziri-web. The introduction page remembers its language under thiziri-site-language. Search and the current reading are processed in page memory. Browser progress is separate from the Android app; there is no account or cross-device sync.

What loading a website means

Your browser requests these pages, scripts, images and bundled readings from the website host. Hosting and security providers may process IP addresses, request times and browser headers in server logs. Collection choices in our links use URL fragments, which are not sent to the host as part of the page request. Thiziri’s code has no worship-progress upload endpoint, advertising, application analytics or contact form. Other Under the Haik pages and host-level services can have their own handling.

Offline files

A service worker scoped to /thiziri/ saves public page and reading files in this browser when supported. These cached files are not your favourites or counters. First loading needs Internet; successful caching enables subsequent offline reading. Browser storage settings, private browsing and eviction can affect availability.

Your controls

In the reader, Settings → Reset progress clears counters only. Delete all local data asks for confirmation, clears the two Thiziri storage keys and restores defaults. It preserves reading files and does not erase unrelated Under the Haik preferences. Browser site-data controls can remove the offline cache, but clearing the entire underthehaik.com origin may also affect the parent website. This action does not erase browser history, bookmarks or browser-account synced copies. Logical deletion is not guaranteed forensic erasure and cannot retract historical hosting logs or user-created copies.

Cookies and browser platform

This section’s code does not set cookies or load third-party scripts. Existing domain cookies may still accompany normal requests under browser rules. Browser/platform diagnostics and extensions are outside this page’s control; we do not promise that nothing ever leaves your device. Pages on the same origin can access origin storage, so path separation is not an independent security boundary.

Questions

For questions about this project or the site, use the contact options on the main Under the Haik website. This reader does not itself collect a support message or email. The main website’s contact and privacy terms apply when you visit it.
