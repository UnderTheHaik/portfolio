Sources and reading guide

Thiziri presents its existing Arabic readings with English and French meanings. References and review notes belong to each reading; a collection label alone does not establish the source or status of every item.

Read the reference and review note beside each text. Source details and count distinctions are preserved from the existing library; no new authenticity claim is made here.

Translation conveys meaning and should be read alongside the Arabic. Where a translation or source note is absent, the page does not invent one.

A personal counter default is a reading aid, not a claim that a particular number is prescribed. Consult the original reference and reading-specific note.

The interactive reader stores favourites and counters locally. Web offline reading depends on saved files in that browser. Android has a separate bundled reading interface and privacy policy; its public release is in preparation.
