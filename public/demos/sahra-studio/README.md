# Sahra Studio

A separate, local fashion website concept based on the supplied editorial template, with 20 supplied photographs and 18 imagined product styles.

Open index.html directly or serve this directory with a static web server. No build or dependencies required.

Includes category filters, search, price sorting, product galleries, illustrative size guide and browser-local bag with quantity controls. Product names, prices and sizes are invented concept content. No checkout, customer data collection or payment integration.

Photos supplied by the user: Nikhil Uttam and Abdul Raheem Kannath / Unsplash. Original image files are preserved in Downloads; website assets are optimized WebP copies.
Hero background removed with the image generation tool; garment retained from supplied photograph.
