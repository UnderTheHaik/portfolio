The brief and approach

Context

A personal project bringing daily adhkar into a free, ad-free Android app and a companion website. The landing page introduces Thiziri and gives visitors a direct route to the web reader.

Development

The companion web reader includes adhkar collections, recitation counters, favourites and controls for language, theme and text size. The website also provides separate web and Android privacy information.
