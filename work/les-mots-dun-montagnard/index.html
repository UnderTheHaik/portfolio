Les mots d’un montagnard.

A reading space for the poetry of Djamel Metref.

Family publishing project
TECHNOLOGIES

HTML · CSS · JavaScript · Static publishing

Visit website ↗

INSIDE THE PROJECT

ContextProblemApproachDesignDevelopmentChallengesResultWhat I learned
01

Context

A family project giving Djamel Metref’s poetry a home online. The public site identifies the collection as created by his daughter. This is a publishing project, not a claimed commercial client engagement.

02

Problem

A growing collection needs to be easy to explore while preserving the rhythm, line breaks and atmosphere of each poem.

03

Approach

Give poems individual pages and organise the archive by theme, date and location. Keep news in its own section so that updates do not interrupt the collection.

04

Design

A book-like desktop layout, quiet serif typography and landscape photography establish a literary setting. On smaller screens, the reading layout adapts to the available space.

05

Development

Static HTML pages, shared CSS and JavaScript support the archive and its filters. Individual URLs make poems directly shareable and readable without an application shell.

06

Challenges

Poetry has different layout needs from ordinary paragraphs. Line lengths, image contrast and small-screen reading must be considered together. Archive metadata also needs to stay consistent as the collection grows.

07

Result

A published French-language poetry collection with individual reading pages, an organised archive and a separate news section. The site presents the author’s actual writing; no audience metrics are claimed.

08

What I learned

The content should determine the interface. For poetry, preserving a comfortable reading rhythm matters more than adding visual effects.
