A FEW THINGS TO KNOW

Where do the readings come from?

The collections include Quranic passages, narrated adhkar and general prayers. Open the information icon for references and review notes. Some reports and the traditional Names list need further individual review; inclusion is not an independent authentication.

Are the counter targets all prescribed?

No. Source-based repetition counts and personal counters are distinguished in the reader. Reading-only entries, including the Names cards, do not set a religiously prescribed count.

Can I use it offline?

Yes, after the reading files have been cached successfully in this browser on a secure connection. Reopen the same address. A first visit needs Internet; clearing website storage or browser cache can remove the offline copy.

Will the website send reminders?

This website does not request notification permission or schedule alarms. Optional native reminders belong to the Android app.
